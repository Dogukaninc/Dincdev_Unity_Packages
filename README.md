# Dincdev_Unity_Packages

This package provides external tools for game development process, which are gets development process to be faster.

## Installation

In Unity, open `Window > Package Manager`, choose `Add package from git URL...` and paste:

```
https://github.com/Dogukaninc/Dincdev_Unity_Packages.git?path=/Packages/com.dincdev.tools
```

Alternatively, add it directly to `Packages/manifest.json`:

```json
"com.dincdev.tools": "https://github.com/Dogukaninc/Dincdev_Unity_Packages.git?path=/Packages/com.dincdev.tools"
```

## Development

This repository is also a Unity project. The package lives at
`Packages/com.dincdev.tools`, so opening the repo in Unity loads it as an
embedded package: edit the scripts in place and the Editor recompiles them
directly, no reinstall needed.
